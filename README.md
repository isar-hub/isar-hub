## 🧭 About Me

I'm **Isar Ahmad**, a CTO and senior backend engineer working on **distributed systems, trading platforms and real-time data infrastructure**.

- **CTO at [OmniMarketX](https://www.omnimarketx.com)**: I lead engineering and own the architecture of a prediction-market and trading platform that is live in production, from the trading engine to the cloud infrastructure.
- **Senior Software Engineer / Quant Engineer at Fractal Street**: I build real-time market-data systems, WebSocket APIs, backtesting tools and AWS production infrastructure.

I started out in Android development and moved into backend engineering, distributed systems and financial technology.

**What I work on:** system architecture · trading infrastructure (orders, positions, pricing, settlement) · real-time systems (Kafka, WebSockets, Redis) · quant and backtesting infrastructure · cloud and CI/CD · engineering leadership (planning, code review, delivery)
