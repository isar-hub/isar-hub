## 🧭 About Me

I'm **Isar Ahmad**, a **CTO and Senior Backend Engineer** focused on **distributed systems, FinTech, trading systems, and real-time data infrastructure**.

Currently, I'm **CTO at OmniMarketX**, leading engineering and owning product architecture for a production prediction-market and trading platform. I work across trading infrastructure, backend architecture, real-time systems, cloud infrastructure, integrations, and engineering delivery.

I'm also a **Senior Software Engineer / Quant Engineer at Fractal Street**, where I build real-time market-data systems, WebSocket APIs, research infrastructure, backtesting systems, and AWS production infrastructure.

I started my career in Android development and gradually moved toward backend engineering, distributed systems, infrastructure, and financial technology.

### What I Work On

- 🏗️ **System Architecture** — scalable backend and trading systems
- 📈 **Trading Infrastructure** — markets, orders, trades, positions, pricing and settlement
- ⚡ **Real-Time Systems** — Kafka, WebSockets, Redis and streaming pipelines
- 🧪 **Quant Engineering** — market data, backtesting and research infrastructure
- ☁️ **Cloud Infrastructure** — AWS, Docker, CI/CD and production reliability
- 👥 **Engineering Leadership** — architecture, planning, code reviews and delivery
- 🚀 **Product Delivery** — taking systems from MVP to production
